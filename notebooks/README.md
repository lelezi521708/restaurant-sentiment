# Notebook 说明

建议负责人和运行顺序：

1. 01_data_eda.ipynb：数据清洗、固定数据划分和探索性分析；
2. 02_preprocessing.ipynb：文本预处理和 TF-IDF 特征实验；
3. 03_svm.ipynb：Linear SVM 实验；
4. 04_naive_bayes.ipynb：Multinomial Naive Bayes 实验；
5. 05_evaluation_error_analysis.ipynb：最终模型比较和错误分析。

组内任务说明使用中文，但用于最终英文报告的图表标题、坐标轴、图例和表格标题必须使用英文。

notebook 应调用 src/ 中的函数，不要复制相同的核心逻辑。合并前需要清除无用输出，并确认从第一格到最后一格可以完整运行。
